About RailConnect

RailConnect is an educational, production-ready Smart Railway Reservation Platform developed as an MCA capstone project. Designed around the real-world operational challenges of the Indian Railway reservation system (IRCTC), it tackles high-concurrency seat locking, fair waitlist queuing, multi-tier cancellation refunds, and modular full-stack Django architecture.

Architectural Pillars

1. Concurrency-Safe Seat Engine

Guaranteed zero double bookings by enforcing row-level locks via select_for_update() inside transaction.atomic blocks and physical database unique constraints.

2. Transparent Refund Tier Matrix

Rule-based refund calculation: 90% refund if cancelled >48 hours before departure, 50% between 12-48 hours, and 0% within 12 hours.

3. Automated Waitlist Queue Engine

Immediate FIFO promotion of waitlisted passengers upon any seat cancellation, without manual administrator intervention.

4. Offline Self-Contained Deployment

Zero external CDN dependency: Bootstrap 5.3 and Chart.js are packaged locally in static/vendor/, ensuring complete offline viva presentation capability.
